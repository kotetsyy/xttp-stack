            ?Rule — трафик идёт по вашим правилам (обычный режим). Global — весь трафик через прокси. Direct — весь трафик напрямую, без прокси.
          

          
          
Rule — по правилам. Global — всё в прокси. Direct — всё напрямую.

        

        

          

            
            ?Silent — логов нет. Error/Warning — только сбои. Info — важные события. Debug — подробный вывод (много данных).
          

          
          
Silent — без логов. Info — важное. Debug — максимум деталей.

        

        

          

            
            ?Off — не определять процесс-источник. Strict — точное определение (может замедлить). Always — всегда пытаться определить процесс.
          

          
          
Off — не искать процесс. Strict — точно (медленнее). Always — всегда пытаться.

Загрузка…

    

    

      
Штатное правило Xray блокирует распознанный BitTorrent только в трафике, проходящем через Xray.

      

        

          
BitTorrent
Блокировать распознанный протокол средствами Xray

          
        

      

      

        Правило в конфигурации: не проверено
        Xray: не проверен
      

      

      

        
      

      
Состояние показывает правило в сохранённой конфигурации и отдельно работу сервиса, а не подтверждённую блокировку всего трафика. DIRECT через Mihomo не покрывается. Шифрование, обфускация и неподдерживаемые варианты BitTorrent могут мешать распознаванию.

      
Изменение перезапускает только Xray и прерывает его текущие соединения. Обновление состояния ничего не меняет.
